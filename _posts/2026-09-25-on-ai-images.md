A few weeks back, I was in an online conversation about the use of AI generated images in blog posts. The prevailing opinion was that if they saw an AI generated image, they stopped reading. The assumption that the rest of the article was AI slop.

I disagreed. I have been using AI-generated images as the banner image of my posts for a while now. The actual written content is all me. The code is usually all me, at least up to now. I was generating cybersteam images because it pleased me. 

When I do use AI-generated code, I'll call that out. It's 2026, using AI to generate code is the new normal now. I won't disagree that we getting a lot of AI-generated slop right now. But it's not all slop. It's tool and it's as effective as it is used. 

If someone doesn't want to read my personal blog because of an AI-generated image, that is more of "them" problem than a "me" problem. I'm the target audience for my blog. There is no advertising and I don't care about metrics. I like the exercise of blogging and it does have some value for other people.

So there may be more AI-gen images in future blog posts. I tend to change things up and my run of steam punk had pretty run it's course.
